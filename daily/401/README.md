# 401. Binary Watch (Easy)

## 問題概要

バイナリ時計は、上部に時（0-11）を表す4つのLED、下部に分（0-59）を表す6つのLEDがあります。
各LEDはビットの重み（1, 2, 4, 8...）を持っており、点灯しているLEDの合計値が現在の時刻を示します。

点灯しているLEDの総数 `turnedOn` が与えられたとき、考えられるすべての時刻をリスト形式で返してください。時刻の形式は "H:MM" とし、分が10未満の場合は先頭に0を付けます。

## 制約

- 0 <= turnedOn <= 10
- 時は 0 から 11 の範囲。
- 分は 0 から 59 の範囲。
