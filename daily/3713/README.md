# 3713. Longest Balanced Substring I (Medium)

## 問題概要
小文字の英字のみからなる文字列 `s` が与えられます。ある部分文字列の中に含まれる**すべての異なる文字の出現回数が等しい**場合、その部分文字列を「バランスが取れた部分文字列」と呼びます。

与えられた文字列 `s` の中で、バランスが取れた部分文字列の最大の長さを求めてください。

例：`s = "abbac"` の場合、`"abba"` は 'a' が2回、'b' が2回出現するためバランスが取れており、長さは 4 です。

## 制約
- 1 <= s.length <= 1000
- s は小文字の英字のみで構成される。
