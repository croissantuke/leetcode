# 799. Champagne Tower (Medium)

## 問題概要

シャンパングラスをピラミッド状に積み、一番上のグラス（0行目）に `poured` リットルのシャンパンを注ぎます。
各グラスは最大 1 リットルを保持でき、それを超えて溢れた分は、その直下にある左右2つのグラスに均等（半分ずつ）に分配されます。

指定された行 `query_row` と列 `query_glass` にあるグラスに、最終的にどれだけのシャンパンが入っているかを 0.0 から 1.0 の範囲で返してください。

## 制約

- 0 <= poured <= 10^9
- 0 <= query_row <= 99
- 0 <= query_glass <= query_row
