# 80. Remove Duplicates from Sorted Array II

## 問題概要

昇順にソートされた整数配列 `nums` が与えられます。
各要素が**最大2回**まで出現するように、インプレース（追加のメモリを使わず）で重複を削除してください。

要素の相対的な順序は保持する必要があります。
結果として、修正された配列の有効な要素数 `k` を返してください。
配列の先頭 `k` 個の要素が正しい状態であれば、それ以降の要素の内容は問いません。

## 制約

- 追加の配列用メモリを確保してはいけない（空間計算量 $O(1)$）。
- 配列はあらかじめソートされている。
